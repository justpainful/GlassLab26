# Build and Signing

## Toolchain

| Item | Value |
|---|---|
| Runner | `macos-26` (GitHub-hosted) |
| Xcode | 26.6, pinned with `XCODE_VERSION` in `.github/workflows/build-ios.yml` |
| SDK | iOS 26.5 (the workflow fails if the SDK is older than 26.0) |
| Deployment target | iOS 26.0 |
| Swift | Swift 6.2 compiler in Swift 5 language mode, minimal strict concurrency |
| Architectures | arm64 (device); simulator for tests |
| Project | generated by XcodeGen from `project.yml` (no third-party packages) |

`macos-latest` is not used. The workflow selects the Xcode path explicitly and prints `xcodebuild -version`,
`swift --version`, the SDK version and the installed simulator runtimes.

## Workflow (`build-ios.yml`)

Triggers: push to `main`, pull requests (no secrets: build + tests + unsigned archive), manual dispatch
(choose export method, UI tests, TestFlight upload).

Job **test**: checkout, select Xcode, verify toolchain, install XcodeGen, generate the project, resolve
dependencies, `build-for-testing` for an iPhone 17 Pro simulator, unit/integration tests, UI tests
(reported, non-blocking), upload `.xcresult` bundles and logs.

Job **archive** (after tests pass): detect signing secrets; if present, create a temporary keychain, import
the certificate and profile, archive with manual signing, export with a generated `ExportOptions.plist`;
otherwise archive with signing disabled and package `GlassLab-UNSIGNED.ipa`. Then verify the IPA (contents,
Info.plist, `lipo`, `codesign --verify` when signed), zip dSYMs, upload IPA, dSYMs and logs, and always delete
the keychain, profile and API key.

## Secrets

Names only; values are never printed (the keychain password is masked).

| Secret | Required for | Content |
|---|---|---|
| `APPLE_CERTIFICATE_P12_BASE64` | signing | base64 of the .p12 (certificate + private key) |
| `APPLE_CERTIFICATE_PASSWORD` | signing | .p12 password (may be empty) |
| `APPLE_PROVISIONING_PROFILE_BASE64` | signing | base64 of the .mobileprovision |
| `APPLE_TEAM_ID` | signing | 10-character Team ID |
| `APP_STORE_CONNECT_KEY_ID` | TestFlight | API key ID |
| `APP_STORE_CONNECT_ISSUER_ID` | TestFlight | issuer ID |
| `APP_STORE_CONNECT_KEY_P8_BASE64` | TestFlight | base64 of AuthKey_XXXX.p8 |

The bundle identifier is taken from the profile's `application-identifier` (wildcard profiles fall back to
`com.justpainful.glasslab`). Add secrets with:

```bash
base64 -i GlassLab.p12 | gh secret set APPLE_CERTIFICATE_P12_BASE64 -R justpainful/GlassLab26
```

```bash
base64 -i GlassLab.mobileprovision | gh secret set APPLE_PROVISIONING_PROFILE_BASE64 -R justpainful/GlassLab26
```

```bash
gh secret set APPLE_TEAM_ID -R justpainful/GlassLab26
```

```bash
gh secret set APPLE_CERTIFICATE_PASSWORD -R justpainful/GlassLab26
```

## Distribution methods

| Input | ExportOptions `method` | Certificate | Profile |
|---|---|---|---|
| development | `debugging` | Apple Development | Development profile listing the device UDIDs |
| ad-hoc | `release-testing` | Apple Distribution | Ad Hoc profile listing the device UDIDs |
| app-store-connect | `app-store-connect` | Apple Distribution | App Store profile; optional TestFlight upload with the API key |

Run manually:

```bash
gh workflow run build-ios.yml -R justpainful/GlassLab26 -f export_method=development
```

## Local build

```bash
brew install xcodegen
```

```bash
xcodegen generate
```

```bash
xcodebuild test -project GlassLab.xcodeproj -scheme GlassLab -destination "platform=iOS Simulator,name=iPhone 17 Pro"
```

Open `GlassLab.xcodeproj`, choose your team under Signing & Capabilities, and run on a device.
